# Mechanism Extraction Contract

Identify mechanisms explicitly proposed, measured, or discussed by the paper.
Separate author claims from direct observations and comparison-based inference.

Rules:

- Use only supplied Unified Document evidence.
- Preserve qualifying language and competing explanations.
- Do not promote correlation to causation.
- Attach valid `evidence_id` values to every mechanism claim.
- Map domain claims only to fields defined by the loaded Domain Extension.
