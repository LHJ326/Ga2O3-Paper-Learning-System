# Ga2O3 Paper Learning System

## 项目目标

建立一个面向 Ga2O3 光电探测器论文的 AI 学习系统，保留从原始论文到结构化知识的完整证据链。

## 当前阶段

Phase 1.2 — Pilot Engineering Environment Setup（项目初始化）。

## Benchmark-driven development

项目采用 Benchmark-driven development：先定义正确答案和评估标准，再测试工具并选择实现方案。当前不提前绑定单一 PDF 解析工具。

## 后续路线

PDF 解析 → 结构化抽取 → Benchmark 评估 → Translation QA → Knowledge Card → RAG → AI Tutor

下一阶段为 Phase 1.3：环境配置与 PDF 解析器评估。
